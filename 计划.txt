# 《肥猫咖啡公司》完整开发计划

## 一、最终游戏形态

游戏类型：

**竖屏手机游戏 / 放置经营 / 猫咪收集 / 工厂升级 / 轻弹射互动**

核心体验：

玩家经营一栋多层“肥猫咖啡工厂”，招聘不同猫咪，让猫咪消耗咖啡豆生产猫屎咖啡，通过升级建筑、装备猫咪、研究科技、购买道具提升收益，并把胖猫弹射到好友工厂偷资源。

---

# 二、推荐技术路线

## 首选方案：Cocos Creator 3.x

更适合这个项目，因为：

* 竖屏 2D UI 游戏非常合适
* APK / iOS / Web 都容易导出
* UI 复刻成本低
* Codex 写 TypeScript 组件比较稳定
* 比 Three.js 更适合大量按钮、弹窗、面板、资源系统

## 备选方案：Three.js

适合做更强的 2.5D 建筑表现，但 UI 系统要自己搭很多，开发成本更高。

## 最终建议

**用 Cocos Creator 3.x + TypeScript 开发。**

```text

↓
```

### 简化 MVP 公式

```text

```

```text

```
