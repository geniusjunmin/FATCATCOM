# FATCATCOM

肥猫咖啡公司游戏项目。

当前仓库包含：

- `FATCATUI/`：Cocos Creator 客户端工程。
- `FATCATServer/`：C# .NET 服务端工程。
- `docs/ai-progress/`：AI 协作开发进度、任务队列和交接记录。
- 根目录 UI 参考图：主页面、猫咪页面、详情页面等目标设计稿。
- `tools/`：本地检查、截图回归和验证脚本。

继续开发前建议先阅读 `docs/ai-progress/00_README.md`、`docs/ai-progress/02_CURRENT_STATUS.md` 和 `docs/ai-progress/03_NEXT_TASKS.md`。
