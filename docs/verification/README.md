# 肥猫咖啡公司验证目录

本目录用于保存后续 UI 截图、检查命令和阶段验收记录。

## 目录

- `screenshots/`：每轮 UI 修改后的截图，建议按 `YYYY-MM-DD-task-viewport.png` 命名。
- `CLIENT_CHECKS.md`：客户端 TypeScript、Cocos 刷新、浏览器验证命令。

## 截图命名

```text
YYYY-MM-DD_B003-cat-overview_390x844.png
YYYY-MM-DD_B001-factory-main_430x932.png
YYYY-MM-DD_B010-shop_768x1024.png
```
